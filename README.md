# WRFCoin testnet support (private, invitees only)

This repository is where invited testnet participants report **bugs and problems**.

## Report a bug
Open an issue with the **Bug report** template. Include:
- what you did, what you expected, and what happened (exact error text);
- the app version (Settings → About) or the web page URL;
- your station ID or **public** wallet address, only if relevant.

**Never include:** recovery words, private keys, API keys or tokens, your precise location, or screenshots that show any of these.

## Report a security issue
**Do not open an issue.** Email **tony@wrfcoin.com** with "[SECURITY]" in the subject. You'll get an acknowledgement within two business days.

## About the testnet
This is a test network. WRF on it has no monetary value, and the chain may be reset.
