# WRFCoin testnet support

## Public testnet

Public launch: **2026-10-22**. Testnet WRF has no monetary value, and the network may be reset.

- [WRFCoin website](https://wrfcoin.com)

- [Security reporting](SECURITY.md)

## Start here

Read the [public testnet quickstart](https://github.com/wrfcoin/docs/blob/main/testnet/quickstart.md),
then use the [support guide](SUPPORT.md) to choose a help category.
Open an [issue](https://github.com/wrfcoin/testnet-support/issues/new/choose) for wallet,
faucet, station connection, node operator help, or a reproducible bug.

Describe the steps, expected behavior, actual behavior, app version or page URL,
and safe error text. Public wallet addresses are optional; only include one if
needed and you are comfortable making it public.

**Never include recovery words, private keys, credentials, tokens, precise location,
or screenshots containing sensitive information.**

For suspected vulnerabilities, email **security@wrfcoin.com** privately.
See [SECURITY.md](SECURITY.md), [CONTRIBUTING.md](CONTRIBUTING.md), and the
[Code of Conduct](CODE_OF_CONDUCT.md).
