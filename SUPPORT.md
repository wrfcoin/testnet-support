# Getting testnet help

Start with the [invitee quickstart](https://github.com/wrfcoin/docs/blob/main/testnet/invitee-quickstart-v3.md)
and the [WRFCoin website](https://wrfcoin.com). Testnet tokens have no monetary value;
the network may be reset. Support does not promise a response time or recovery of funds.

## Choose an issue template

Open the [issue chooser](https://github.com/wrfcoin/testnet-support/issues/new/choose):

- **Wallet help:** trouble creating or unlocking a wallet, receiving, or sending.
- **Faucet help:** a test-token request fails or does not appear.
- **Station connection help:** trouble connecting a weather station or submitting data.
- **Node operator help:** setup, synchronization, or peer-connectivity questions.
- **Bug report:** other reproducible problems.
- **Feature request:** suggestions for improvements.

For operator background, read the [operator guide](https://github.com/wrfcoin/docs/blob/main/testnet/operator-guide.md).
Describe the app/version, steps taken, expected result, actual result, and safe error
text. Mention approximately when it happened. Review attachments before posting.

## Keep private information private

Never post recovery words, private keys, passwords, API keys, access tokens, precise
coordinates, private host addresses, or unredacted logs. A public wallet address or
transaction hash is optional and links activity publicly; include it only when needed.
No legitimate helper needs your recovery words or private keys.

Report suspected vulnerabilities to **security@wrfcoin.com**, following
[SECURITY.md](SECURITY.md), instead of opening a public issue.
